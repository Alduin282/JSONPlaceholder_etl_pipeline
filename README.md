# JSONPlaceholder ETL Pipeline

Надежный и производительный ETL-конвейер для загрузки данных из JSONPlaceholder API в локальную базу данных SQLite.

## Особенности

- **Нормализованная схема**: Данные `address` и `company` вынесены в отдельные таблицы для строгой типизации и удобства аналитики.
- **Geo-flattening**: Поля координат (`lat`, `lng`) расплющены в `geo_lat` и `geo_lng`.
- **Атомарность**: Загрузка пользователя (основная запись + связи) происходит внутри одной SQL-транзакции.
- **Идемпотентность**: Использование `UPSERT` (ON CONFLICT DO UPDATE) позволяет запускать скрипт многократно без дублирования данных.
- **Отказоустойчивость**: Реализована логика повторных попыток (Retry) с экспоненциальной задержкой для сетевых ошибок (3 попытки всего: 1 основная + 2 ретрая).
- **Валидация**: Строгая проверка типов через Pydantic v2 (пропуск битых записей с логированием).

## Архитектура

Проект построен по принципу разделения ответственности:
- `api_client.py`: Общение с внешним миром (HTTP, Retry).
- `repository.py`: Единственная точка входа в БД (DDL, SQL).
- `loader.py`: Оркестрация процесса (оркестрирует вызовы API и Repository).
- `db.py`: Управление жизненным циклом соединений и транзакций через контекстный менеджер.
- `models.py`: Схемы данных и методы преобразования объектов для БД.

## Схема базы данных

```
   [users]           [posts]            [comments]
   id (PK) <─────┐   id (PK) <─────┐    id (PK)
   name          └─  user_id (FK)  └─   post_id (FK)
   username          title              name
   email             body               email
   phone                                body
   website

   [user_addresses]      [user_companies]
   user_id (PK, FK) ──>  user_id (PK, FK) ──> (to users.id)
   street                name
   suite                 catch_phrase
   city                  bs
   zipcode
   geo_lat
   geo_lng
```

## Быстрый старт

### 1. Установка зависимостей
```bash
python -m venv .venv
source .venv/bin/activate  # Или .venv\Scripts\activate на Windows
pip install -r requirements.txt
```

### 2. Запуск ETL
```bash
python main.py
```

После завершения появится файл `jsonplaceholder.db`.

## Конфигурация

Все настройки находятся в `src/config.py`:
- `DB_PATH`: Путь к базе данных (по умолчанию `jsonplaceholder.db`).
- `MAX_RETRIES`: Количество повторных попыток (по умолчанию 2, итого 3 попытки).
- `REQUEST_TIMEOUT`: Таймаут запроса (30 сек для стабильной загрузки `/comments`).

## Логирование

По умолчанию выводится в stdout с уровнем `INFO`. Логи содержат информацию о количестве успешно провалидированных и сохраненных записей, а также предупреждения о пропусках при ошибках валидации.
