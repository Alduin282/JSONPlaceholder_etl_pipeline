Правила написаний тестов на пайтон:
1. тесты должны быть в папке tests
2. для каждого модуля свой файл с тесатми
3. нейминг тестов по съеме test__<given>__<when>__<then>
4. размечаем области тестов комментариями - # Arrange # Act # Assert
5. В одном тесте 1 проверка 
6. тесты - просто функции
7. @pytest.fixture - всегда используем для анчальной инициализации только это
